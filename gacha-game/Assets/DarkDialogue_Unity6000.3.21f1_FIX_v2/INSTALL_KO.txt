Dark Dialogue — Unity 6000.3.21f1 직접 설치판

1. Unity에서 현재 떠 있는 Import Unity Package 창을 닫으세요.
2. 이 ZIP 파일을 압축 해제하세요.
3. 압축을 푼 Assets 폴더 안의 DarkDialogue 폴더와 DarkDialogue.meta를
   내 Unity 프로젝트의 Assets 폴더에 복사하세요.
   예: 내프로젝트/Assets/DarkDialogue/Prefabs/DarkDialogue.prefab
4. Unity로 돌아가 파일을 읽고 스크립트를 컴파일할 때까지 기다리세요.
5. Project에서 DarkDialogue.prefab을 Hierarchy 최상위에 드래그하고 Play.
