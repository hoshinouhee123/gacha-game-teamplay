- **민효주**: 아트 담당

## 프로그래밍 할때 참고할 내용 정리

### AudioManager를 통한 사운드 재생 방법 예시 코드
``` C#
AudioManager.Instance.PlayBGM(bgmClip);		// BGM 재생
AudioManager.Instance.PlaySFX(clickSound);		// SFX 재생
AudioManager.Instance.PlayVoice(characterVoice);	// 캐릭터 보이스 재생
```
